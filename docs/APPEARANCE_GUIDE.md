# 外觀客製化功能使用指南

## 功能概述

外觀客製化功能讓管理員可以為每個租戶設定獨特的聊天視窗外觀,包括標題、顏色、歡迎訊息等。

## 可客製化項目

### 1. 標題設定
- **主標題**: 聊天視窗頂部的主要標題 (如: "Wi帶你逛 - 智慧導購")
- **副標題**: 主標題下方的副標題 (如: "Syntrend AI Assistant")

### 2. 訊息設定
- **歡迎訊息**: 使用者開啟聊天時顯示的第一則訊息
- **輸入框提示文字**: 輸入框的 placeholder 文字

### 3. Header 顏色
- **單色模式**: 選擇單一顏色
- **漸層模式**: 
  - 支援 2-5 個顏色
  - 可選擇漸層方向 (向右/向下/對角)
  - 可新增/刪除顏色

### 4. 按鈕顏色
- **單色模式**: 選擇單一顏色
- **漸層模式**: 支援 2 個顏色的漸層

### 5. 聊天圖示
- 上傳自訂圖示
- 檔案限制: < 5MB
- 支援格式: PNG, JPG, JPEG, WebP
- 自動壓縮至 128x128px

## 使用步驟

### 1. 進入外觀設定頁面

1. 登入管理後台 (`http://localhost:3000/admin/login`)
2. 進入租戶管理頁面
3. 點擊要編輯的租戶的「外觀」按鈕
4. 進入外觀編輯器

### 2. 編輯外觀設定

#### 標題與訊息
1. 在「標題設定」區塊輸入主標題和副標題
2. 在「訊息設定」區塊輸入歡迎訊息 (支援多行)
3. 輸入輸入框提示文字

#### Header 顏色
1. 選擇「單色」或「漸層」模式
2. **單色模式**: 點擊顏色選擇器選擇顏色
3. **漸層模式**:
   - 為每個顏色點擊選擇器選擇顏色
   - 點擊「+ 新增顏色」新增更多顏色 (最多 5 個)
   - 點擊「刪除」移除顏色 (最少 2 個)
   - 選擇漸層方向

#### 按鈕顏色
1. 選擇「單色」或「漸層」模式
2. 選擇顏色 (漸層模式固定 2 個顏色)

#### 上傳圖示
1. 點擊「選擇檔案」或拖放圖片
2. 等待上傳完成
3. 預覽區會顯示新圖示

### 3. 即時預覽

右側預覽區會即時顯示外觀變化:
- Header 顏色與標題
- 歡迎訊息樣式
- 使用者訊息氣泡顏色
- 輸入框提示文字
- 按鈕顏色

### 4. 儲存設定

1. 確認預覽效果無誤
2. 點擊「儲存設定」按鈕
3. 等待儲存成功提示
4. 前往聊天頁面查看實際效果

## API 端點

### 取得外觀設定
```
GET /admin/tenants/{tenant_id}/appearance
Headers: X-Admin-Key: your_admin_key
```

### 更新外觀設定
```
PUT /admin/tenants/{tenant_id}/appearance
Headers: X-Admin-Key: your_admin_key
Body: {
  "title": "...",
  "subtitle": "...",
  "welcomeMessage": "...",
  "placeholder": "...",
  "header": { ... },
  "button": { ... },
  "chatIconUrl": "..."
}
```

### 上傳圖示
```
POST /admin/tenants/{tenant_id}/appearance/upload-icon
Headers: X-Admin-Key: your_admin_key
Body: FormData with 'file' field
```

## 資料結構

```json
{
  "title": "Wi帶你逛 - 智慧導購",
  "subtitle": "Syntrend AI Assistant",
  "welcomeMessage": "Hi！我是智慧導覽助手 🤖\n我可以幫您：\n• 🗺️ 規劃路線\n• 🎯 個人化推薦",
  "placeholder": "請輸入想要詢問的問題?",
  "header": {
    "type": "gradient",
    "colors": ["#f97316", "#eab308", "#a855f7"],
    "direction": "to right"
  },
  "button": {
    "type": "solid",
    "color": "#f97316"
  },
  "chatIconUrl": "/images/tenants/demo/chat-icon.png"
}
```

## 注意事項

1. **圖片大小**: 上傳的圖片會自動壓縮至 128x128px,建議上傳正方形圖片
2. **顏色對比**: 確保文字與背景顏色有足夠對比度,避免閱讀困難
3. **即時生效**: 儲存後立即生效,無需重啟服務
4. **預設值**: 如果未設定外觀,會使用預設的三創橘色配色

## 疑難排解

### 圖片上傳失敗
- 檢查檔案大小是否 < 5MB
- 確認檔案格式為 PNG, JPG, JPEG 或 WebP
- 檢查網路連線

### 顏色未套用
- 確認已點擊「儲存設定」
- 重新整理聊天頁面
- 檢查瀏覽器快取

### 預覽與實際不符
- 清除瀏覽器快取
- 確認租戶 ID 正確
- 檢查後端 API 是否正常運作

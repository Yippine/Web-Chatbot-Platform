# Web Chatbot Platform：品牌與服務架構——白話版

這份文件用最簡單的語言，解釋我們的聊天機器人平台裡「品牌」和「服務」是什麼關係、聊天室的標籤按下去會發生什麼事，以及系統如何記住對話。

---

## 1. 品牌和服務是什麼關係？

想像一間連鎖飲料店：

- **品牌（Brand）** 就像整個連鎖品牌，決定了招牌顏色、店名、Logo 是什麼樣子
- **服務（Service）** 就像這個品牌底下的不同「服務員」，每個服務員有自己的專長和說話方式

所以：
- 一個品牌可以有很多個服務
- 每個服務都有自己的「個性設定」（技術上叫做 system prompt，就是一份描述這個服務員如何回答問題的說明文件）
- 品牌負責外觀（頁面標題、顏色、歡迎語），服務負責實際對話內容

**舉個例子：**
品牌叫「Leo 汽車」，底下有三個服務：
- 「詢問車款」服務 → 專門回答車型介紹
- 「預約試駕」服務 → 專門協助預約
- 「維修保養」服務 → 專門解答保養問題

---

## 2. 聊天室裡按下服務標籤，只發生一次還是一直生效？

**答：一直生效，直到你切換或退出為止。**

按下服務標籤後，就像切換到那個服務員的「模式」：

1. 輸入框上方會出現一條提示，告訴你「現在是 XXX 模式」
2. 你接下來說的每一句話，都會交給這個服務來回答
3. 如果你想換回一般模式，按「退出模式」按鈕即可

**這就像你走進一個專屬服務視窗，你不離開，服務員就一直是同一個。**

---

## 3. 直接打字 vs 按標籤，有什麼不同？

系統提供兩種方式讓你選擇要哪個服務回答：

### 方式一：按標籤
你主動點選某個服務標籤，系統直接切換到那個服務，**不會再多想一步**，就是你點的那個。

### 方式二：直接打字
你不按任何標籤，直接輸入文字。這時系統會**每一輪都自動判斷**你說的話最適合哪個服務，然後自動切換過去幫你回答。

這個自動判斷的機制叫做「意圖辨識（detectIntent）」，就像一個接待員幫你判斷「這個客人的問題應該轉給哪個部門」。

**所以：按標籤 = 你自己選；直接打字 = 系統幫你選。**

---

## 4. 每次回覆都要重新傳入服務說明，字數很多不會很慢或很貴嗎？

**不會，因為「服務說明」和「對話記錄」是分開放的。**

讓我們用更簡單的方式理解：

假設你打電話給客服，每次接通時：
- 客服手冊（服務說明）：每次通話都會攤開在客服面前，**但這本手冊是放在桌上的，不算通話費**
- 對話記錄（你說過的話）：系統另外記在一個本子上，這個本子才會越記越滿

在我們的系統裡：
- 「服務說明（system prompt）」走的是一個獨立的欄位，Gemini AI 的計費方式本來就是把它分開算，不會跟對話記錄混在一起
- 「對話記錄」才是真正累積的東西，而且系統限制最多記 **8 輪對話（16 則訊息）**，超過就自動刪掉最舊的，不會無限膨脹

---

## 5. 對話歷史記在哪裡？可以修改嗎？

**記在 Redis（一種高速記憶體資料庫），不能修改。**

### Redis 是什麼？
就是一個超快的「暫存記憶體」，專門用來記住「這個用戶和這個服務說過哪些話」。

### 怎麼記的？
系統用一個像「門牌號碼」一樣的格式來存：

```
gemini_session : 品牌名稱 : 服務名稱 : 用戶ID
```

**這個設計有一個很重要的含義：**
> **換一個服務 = 換了一個新的記憶空間 = 之前說的話全部不算**

所以如果你從「詢問車款」服務切換到「預約試駕」服務，AI 不會記得你剛才問過什麼車，因為它們是完全獨立的對話記憶。

### 生命週期是什麼？
- 每說一輪，就新增一條記錄
- 超過 8 輪（16 條）：最舊的那幾條會被自動刪掉
- 超過 1 小時沒有對話：這個記憶空間整個清除，下次從頭開始

### 可以修改歷史嗎？
**不行。** 已經送出的對話就存進去了，無法回頭更改。系統只會「往後加」，不會「往前改」。

---

## 6. 整體流程用一張圖說清楚

### 情況一：你按了服務標籤

```
你點「詢問車款」標籤
  ↓
系統記住「目前是詢問車款模式」（一直記著，直到你切換）
  ↓
你打了一句話送出
  ↓
後端找到「詢問車款」這個服務的說明文件（system prompt）
  ↓
從 Redis 撈出你和「詢問車款」服務之前說過的話（歷史記錄）
  ↓
把【說明文件 + 歷史記錄 + 你這句新話】一起送給 Gemini AI
  ↓
AI 回答 → 回答存進 Redis → 超過 8 輪就截掉最舊的
```

### 情況二：你直接打字（沒按任何標籤）

```
你打了一句話送出
  ↓
系統先判斷「這句話最適合哪個服務來回答？」（意圖辨識，每輪都做）
  ↓
自動切換到對應的服務
  ↓
後續流程和情況一一樣
```

## 重點整理

| 問題 | 答案 |
|---|---|
| 品牌和服務是什麼關係？ | 品牌是外殼（外觀），服務是裡面的功能模組，各有自己的 AI 說明 |
| 按服務標籤只觸發一次嗎？ | 不是，是切換模式，一直生效到你退出 |
| 直接打字有意圖辨識嗎？ | 有，每一輪都判斷一次，自動選服務 |
| 每輪重傳服務說明會很貴嗎？ | 不會，服務說明和對話記錄分開計算 |
| 對話最多記幾輪？ | 8 輪（16 則），超過自動截斷 |
| 歷史可以修改嗎？ | 不行，只能往後加，不能往前改 |
| 切換服務後歷史還在嗎？ | 還在，但暫時看不見。切回同一個服務會接續上次對話；超過 1 小時不對話才真正清除 |
